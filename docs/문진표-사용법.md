# 문진표 사용법

진료 전에 환자가 휴대폰으로 작성하는 전신 문진표입니다.
원내 종이 문진표 두 가지(전신 문진표·성격과 감정의 문진)를 옮겼습니다.

앱을 내려받거나 로그인할 필요가 없고, 중간에 닫아도 이어서 작성됩니다.

## 주소

```
https://healim-jamsil.com/survey/
```

검색에는 잡히지 않습니다(`noindex`). 링크와 QR로만 들어옵니다.

## 가장 중요한 것 — 병원으로 자동으로 오지 않습니다

**환자가 적은 내용은 그 환자의 휴대폰에만 남습니다.** 본원 서버로도, 다른 회사
서버로도 보내지 않습니다. 환자가 직접 복사해 보내거나 인쇄해 오셔야 합니다.

이렇게 만든 이유가 있습니다. 증상·복용약·병력은 「개인정보 보호법」 제23조의
민감정보입니다. 구글폼처럼 국외 서버에 저장하면 제28조의8(국외 이전)에 따라
별도 동의를 받아야 하고, 홈페이지 개인정보처리방침도 고쳐야 합니다.
받지 않으면 그 의무가 생기지 않습니다.

그래서 운영에서 두 가지를 지켜야 합니다.

**① 작성 직후에 보내거나 인쇄하도록 안내합니다.**
브라우저 기록을 지우거나, 다른 기기로 열거나, 시크릿 모드로 열면 사라집니다.

**② 문항을 고치면 그때 작성 중이던 내용이 사라집니다.**
문항이 바뀐 답을 엉뚱한 칸에 되살리지 않으려고 버리도록 만들었습니다.
진료시간이 아닐 때 고치는 것이 안전합니다.

## 환자에게 건네는 세 통로

| 상황 | 방법 |
|---|---|
| 비대면 진료 | 카카오톡 채널로 링크 전송 |
| 내원 예약 후 | 예약 확정 안내에 링크 함께 |
| 대기실·접수처 | QR 인쇄해서 비치 |

보내실 때 함께 쓰면 좋은 문구입니다.

> 진료 전에 몸 상태를 미리 여쭙는 문진표입니다. 20분쯤 걸리고, 중간에
> 닫으셔도 이어서 쓰실 수 있습니다. 다 쓰신 뒤 「내용 복사」를 눌러
> 이 대화창에 붙여넣어 주세요.

## 환자가 하는 일

링크를 열고 → 20개 화면을 넘기며 해당하는 항목에 표시 → 마지막 「정리된 내용」에서
아래 셋 중 하나를 고릅니다.

| 단추 | 쓰는 곳 |
|---|---|
| 내용 복사 | 아무 데나 붙여넣기 |
| 복사하고 카카오톡 열기 | 비대면 — 복사한 뒤 채널 대화창이 열립니다 |
| 인쇄 · PDF 저장 | A4 한 장. 지참하거나 파일로 보냅니다 |

접수처에서는 마지막 화면을 그대로 보여드려도 됩니다.

## 받는 형태

표시한 항목만 묶음별로 모입니다. 그대로 차트에 붙여넣으시면 됩니다.

```
문진표 2026-09-04

▸ 기본     여성 · 42세 · 162cm · 54kg
▸ 주증상   ① 불면, 2년
           ② 두통·뒷목결림, 6개월
           복용 졸피뎀 10mg 3개월
           병력 갑상선 기능저하증, 2019년 진단
▸ 한열     추위 많이 · 손·아랫배 냉 · 겨울 양말 · 안면홍조·상열감(오후)
▸ 대변     1일 1회 · 딱딱 · 잔변감 · 설사 잦음(찬 음식·기름진 음식) → 경미
▸ 수면     수면 1시~7시 · 수면제·안정제 현재 · 중도각오 · 재입면 곤란 ·
           커피 2잔 · 커피 → 수면 지장 큼
▸ 성격·음양 내성·정적·침울(陰) · 온순·원만(陰) · 화 잘 안 냄(陰)
▸ 감정     가까움 ②걱정·⑥화병·⑦우울 · 멂 ①화·①흥분
```

- 표시가 없는 항목은 「해당 없음」이 아니라 **「표시하지 않음」**입니다.
- 숫자칸을 비우면 `?`로 나옵니다. 원본 문진표에서 헷갈리는 항목에 쓰는 표시와 같습니다.
- 성격 문항의 `(陽)`·`(陰)`은 원본 대비표의 어느 칸을 골랐는지입니다.
  **점수는 매기지 않습니다** — 합산해서 유형을 단정할 자료가 아닙니다.

인쇄본은 전 항목을 표시해도 **A4 한 장**입니다. 차트에 그대로 끼웁니다.

## 종이와 다르게 한 곳

원본을 그대로 옮기지 않은 곳입니다. 되돌릴 수 있습니다.

1. **서로 반대되는 체크칸을 택1로 바꿨습니다.** 종이에서는 네모가 두세 개지만
   내용이 배타적이라, 그대로 두면 둘 다 체크된 답이 들어옵니다.
   — 대변, 식욕·소화, 수면(2곳)
2. **숫자칸과 택1이 한 문장이던 것을 둘로 나눴습니다.**
   — 「술 1주일에 __번 (많이, 조금) 마신다」, 「생리주기 __일 (규칙적, 불규칙적)」
3. **한 체크칸에 딸린 괄호 선택지를 별도 문항으로 뺐습니다.**
   — 「평소 잘 붓는다 (부위 / 오전, 오후)」, 「비염이 있다 (증상 / 사계절·환절기)」
4. **「성관계 후 하복통이나 골반통」 문항을 뺐습니다.**
5. **성격 문진의 陽·陰 대비 쌍을 택1로 묶었습니다.** 한 칸에 동의어가 여럿이던
   것(「외향적 / 활동적 / 밝고 쾌활한 성격」)은 한 선택지로 합쳤습니다 —
   셋 중 어느 것을 골랐는지는 남지 않습니다. 원본 그림 12장은 넣지 않았습니다.

## 문항 고치기

고칠 곳은 **`data/survey.yaml` 한 파일**입니다. 레이아웃과 CSS는 손대지 않습니다.
문항을 늘리면 화면에도 그대로 늘어납니다.

파일 맨 위에 문법과 규칙이 적혀 있습니다. 자주 쓰는 것만 옮기면 —

```yaml
- type: choice          # 문장 속 택1. text 의 {} 자리에 선택지가 들어간다
  text: "추위를 {} 탄다"
  options: [약간, 보통, 많이, 어마어마하게]
  short: "추위 {}"      # 요약(차트용)에 쓸 표현

- type: check           # 단독 체크
  text: "겨울에 양말을 신고 잘 때가 많다"
  short: "겨울 양말"
  detail:               # 체크하면 나오는 하위 택다
    options: [찬 음식, 매운 음식, 기름진 음식, 긴장하면]
  note: "그 밖에 어떤 상황에서?"   # 체크하면 열리는 서술칸
  when: female          # 여성에게만 보인다
```

**요약 표기(`short`)가 원장이 고치는 자리입니다.** 화면 문장은 그대로 둔 채
차트에서 쓰시는 말로 바꿀 수 있습니다.

규칙이 하나 있습니다 — `short` 안에 **앞뒤 공백을 둔 `·`를 쓰지 않습니다.**
요약에서 항목을 잇는 기호라 두 항목처럼 읽힙니다. 붙여 쓴 `손·발`은 괜찮고,
나눌 때는 `/`나 괄호를 씁니다.

고친 뒤에는 이 세 가지를 확인합니다.

```
hugo --gc                    # 빌드가 통과하는가 (--minify 를 붙이지 않는다)
python3 tools/check-mobile.py  # 모바일 규칙이 빠지지 않았는가
```

브라우저를 390px 폭으로 줄여 가로 스크롤이 생기지 않는지도 봅니다.

## 지금은 안 되는 것

| | |
|---|---|
| 자동 수집 | 환자가 보내지 않으면 병원에 아무것도 오지 않습니다 |
| 통계·추이 | 여러 환자의 답을 모아 보는 화면이 없습니다 |
| 재진 비교 | 다시 쓸 때 이전 답이 남아 있어 빠르지만, 「지난번과 달라진 것」을 뽑아 주지는 않습니다 |

자동으로 받으려면 국내 수신 서버가 필요하고, 그때부터 민감정보 수집이라
동의 절차와 개인정보처리방침 개정이 따라옵니다.

| `layouts/survey.html` | 페이지 틀 |
| `layouts/_partials/survey-item.html` | 문항 하나를 그리는 마크업 |
| `static/js/survey.js` | 화면 이동 · 브라우저 저장 · 요약 만들기 |

| `static/_headers` | `/survey/*` 에 noindex |
| `assets/css/site.css` | 맨 끝 「문진표」 블록 |
