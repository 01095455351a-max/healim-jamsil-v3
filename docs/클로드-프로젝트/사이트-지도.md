## 참고자료로 쓰는 기관

주소는 **여기서 쓰지 않는다.** 기관명과 문서 제목만 적고 넘긴다.

**국내 자료를 먼저 찾는다.** 한의원 홈페이지의 글이므로 한의표준임상진료지침과
국내 학회·공공기관 자료가 근거로 더 맞다. 국내 자료를 앞에, 해외 기관을 뒤에 둔다.

| 국내 | 무엇 |
|---|---|
| 국가한의임상정보포털(한국한의약진흥원) | 한의표준임상진료지침 |
| 대한한방신경정신과학회 | 동의신경정신과학회지 |
| 국가정신건강정보포털(국립정신건강센터) | 질환별 안내 |
| 국가건강정보포털(질병관리청) | 질환별 안내 |

한의표준임상진료지침이 나와 있는 것 — **불면장애 · 우울증 ·
불안장애 · 화병 · 기능성 소화불량 · 자율신경실조증 · ADHD · 과민대장증후군 ·
긴장성 두통 · 현훈**. 이 사이트의 질환과 많이 겹친다.

**지침에서는 정의 · 진단 기준 · 감별 · 위험 신호 · 의뢰 기준만 가져온다.**
치료 권고(「~를 고려해야 한다」), 권고등급·근거수준, 「양약에 비해 ○○」 같은 비교,
연구 결과는 인용하지 않는다. 등급을 붙여도 환자는 「효과가 입증됐다」로 읽고,
「양약에 비해 한약」을 읽고 복용하던 약을 끊을 수 있다. 치료를 설명하는 대목에서
지침을 근거로 삼지 않는다.

해외 기관은 국내에 마땅한 자료가 없을 때 쓴다.

| 약자 | 한국어 이름 |
|---|---|
| NINDS | 미국 국립신경질환뇌졸중연구소 |
| NIMH | 미국 국립정신건강연구원 |
| NHLBI | 미국 국립심폐혈액연구소 |
| CDC | 미국 질병통제예방센터 |
| NHS | 영국 국민보건서비스 |
| NICE | 영국 국립보건의료연구원 |
| WHO | 세계보건기구 |
| Cleveland Clinic | 클리블랜드 클리닉 (약자를 쓰지 않는다) |
| American Heart Association | 미국심장협회 |

**약자로만 적지 않는다.** 한국어 이름을 앞에 쓰고 약자를 괄호에 넣는다 —
환자가 「NHLBI」를 보고 어디인지 알 수 없다. 표에 없는 기관은 그 기관이 스스로
쓰는 한국어 이름을 찾아 쓰고, 없으면 영문 이름을 그대로 둔다. 지어내지 않는다.

**NICE CKS(`cks.nice.org.uk`)는 쓰지 않는다.** 영국 밖에서는 구독자만 열려
환자가 눌러도 열리지 않는다. `nice.org.uk/guidance/...`는 열리므로 그쪽은 된다.

형식은 컬럼마다 같다.

```markdown
## 참고자료

*아래 자료는 모두 외부 기관이 제공하는 정보로, 클릭하시면 새 사이트로 연결됩니다.*

1. 한국한의약진흥원 — 우울증 한의표준임상진료지침  [주소 확인 필요]
2. 미국 국립정신건강연구원(NIMH) — 출산 전후 우울  [주소 확인 필요]
```
