# 클로드 프로젝트 — 컬럼 초고용

claude.ai의 **프로젝트** 하나를 컬럼 초고 전용으로 쓴다. 원고는 거기서 쓰고,
사이트에 앉히는 일(내부 링크·참고자료 주소 확인·front matter·빌드·CMS 올리기)은
저장소가 있는 Claude Code에서 한다.

프로젝트에는 저장소가 없다. **없는 주소를 지어내는 것을 막는 것**이 이 폴더의 목적이다.

## 프로젝트에 올리는 것

| 파일 | 올리는 곳 |
|---|---|
| `프로젝트-지침.md` | 프로젝트 **「지침」 칸에 붙여넣기** |
| `사이트-지도.md` | 프로젝트 지식 |
| `../컬럼-작성-가이드.md` | 프로젝트 지식 |
| `../컬럼-계획표.md` | 프로젝트 지식 — 무엇을 쓸지 여기서 고른다 |
| `../../content/column/why-insomnia-becomes-chronic.md` | 프로젝트 지식 — 석선희 원장 문체 견본 |
| `../../content/column/why-tics-wax-and-wane.md` | 프로젝트 지식 — 류석균 원장 문체 견본 |

견본 컬럼은 실제 발행된 글을 그대로 올린다. 따로 사본을 만들지 않는다.

## 언제 다시 올리는가

**`사이트-지도.md`가 어긋나면 프로젝트가 없는 주소로 링크를 건다.**
아래를 고치면 이 파일도 같이 고치고, 프로젝트 지식의 파일을 새로 올린다.

- 질환 페이지를 더하거나 지웠을 때 (`content/diseases/`)
- 태그를 새로 만들었을 때
- 치료 방법을 더하거나 이름을 바꿨을 때 (`data/treatments.yaml`)
- 원장이 늘거나 진료 분야가 바뀌었을 때 (`data/authors/`)
- 컬럼을 발행했을 때 — 「이미 있는 컬럼」 표에 한 줄 (주제 중복을 막는 목록이다)
- 컬럼을 발행했을 때 — `../컬럼-계획표.md`의 해당 칸에도 ✅를 넣는다
- 아직 안 보여주던 페이지를 공개했을 때 (지금은 비급여안내 `/pricing/`)

## 원고가 넘어오면

프로젝트에서 나온 원고에는 **「확인 필요」 목록**이 붙어 있다. 여기서 처리한다.

1. 참고자료 주소 — `WebSearch`로 실제 존재하는 주소를 확인해 채운다. 확인 안 되면 뺀다
2. `[[링크: ...]]` 표시 — 실제 주소로 바꾸거나, 갈 곳이 없으면 링크를 없앤다
3. 의학적 수치 — 원장 검수 항목으로 남긴다
4. `date`·`lastmod`를 발행일로 채운다
5. 빌드·점검 후 CMS 초안(`cms/column/<슬러그>` 브랜치)으로 올린다

「확인 필요」가 비어 있는 원고는 의심한다. 대개 무언가를 지어낸 것이다.
