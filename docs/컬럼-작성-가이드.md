# 원장 컬럼 쓰는 규칙

이 파일은 새 컬럼을 쓸 때 먼저 읽는다. 기존 12편에서 실제로 뽑아낸 규칙이며,
문체가 흔들리지 않게 하는 것이 목적이다.

공지사항은 규칙이 훨씬 단순하다 — 맨 아래 「공지사항」 절을 본다.

claude.ai의 **프로젝트**에서 초고를 쓸 때는 이 파일과 함께 `docs/클로드-프로젝트/`의
`사이트-지도.md`를 지식으로 올린다. 그쪽에는 저장소가 없어 주소를 확인할 수 없다.
올리는 파일과 다시 올릴 시점은 `docs/클로드-프로젝트/README.md`에 적어 두었다.


## 무엇을 누가 하는가

이 경계를 넘지 않는다.

| | 하는 일 |
|---|---|
| **원장** | 주제 결정 · 의학 내용 검수 · 참고자료 확인 · 발행 승인 |
| **Claude** | 초안 작성 · 형식 · 중복 확인 · 표현 점검 · 빌드 검증 · 커밋·푸시 |

**의학적 사실을 지어내지 않는다.** 확실하지 않으면 그 문장을 비워 두고
원장에게 묻는다. 이 저장소에는 홈의 학술 논문이 가짜 제목으로 채워져 있던
전례가 있다(`CLAUDE.md` 참고). 같은 일을 반복하지 않는다.

**원장 검수 전에는 발행하지 않는다.** 컬럼은 `authors` 값으로 원장 이름이 붙고
구조화 데이터에도 저자로 나간다. 원장이 쓴 글로 표시된다.


## 집 문체

기존 12편을 실측한 값이다.

글자 수는 **바이트가 아니라 글자로 센다.** 한글은 UTF-8에서 3바이트라 두 배 넘게
부풀려진다(`wc -m`이 이 환경에서 바이트를 센다). 한때 이 표에 바이트 값이 「자」로
적혀 있어 목표가 실제의 두 배였다. 셀 때는 이렇게 한다.

```
python3 -c "import io,sys;print(len(io.open(sys.argv[1],encoding='utf-8').read().split(chr(45)*3,2)[2]))" content/column/<파일>.md
```

| | |
|---|---|
| 본문 길이 | 2,700 ~ 3,300자 (짧게는 1,700, 길게는 5,000). 평균 3,167자 |
| 소제목(`##`) | 9 ~ 11개 |
| 자주 묻는 질문 | 2 ~ 3개 |
| 말투 | 존댓말. 「~습니다」 |
| 문단 | 3 ~ 5문장. 길어지면 나눈다 |

### 뼈대

앞뒤 두 개와 마지막 세 개는 거의 고정이다. 가운데만 주제에 따라 달라진다.

```
(제목 없이) 환자가 실제로 하는 말 3줄을 따옴표로 인용
            → 요지 한 문단. 질환 페이지로 링크를 건다

## 먼저 결론부터 말씀드리면        12편 중 8편
## (주제별 소제목 4~6개)
## 한의학에서는 어떻게 이해할까요?   12편 중 10편
## 자주 묻는 질문                  12편 중 12편
## 마무리                         12편 중 10편
## 참고자료                       12편 중 12편
```

### 도입부

첫 세 줄은 **환자가 진료실에서 실제로 하는 말**을 따옴표로 적는다.
증상 나열이 아니라 사람의 말이어야 한다.

```markdown
"처음에는 스트레스 때문에 못 잤는데 이제는 이유 없이 잠이 안 옵니다."
"오늘도 못 자면 어떡하나 걱정하면 더 또렷해져요."
"피곤한데 침대에만 누우면 정신이 맑아집니다."

단기 [불면](/diseases/insomnia/)은 스트레스나 생활 변화로 시작할 수 있지만,
잠에 대한 걱정과 불규칙한 수면 습관이 더해지면 처음 원인이 사라진 뒤에도
지속될 수 있습니다.
```

### 마무리

`## 마무리` 구역 끝에 이 네 줄을 붙인다. 형식을 바꾸지 않는다.

```markdown
관련 컬럼: [제목](/column/파일명/)

**작성자**: [석선희 원장](/doctors/seok-seonhui/) ｜ 한방신경정신과 전문의
**작성일**: 2026년 9월 1일
**검토일**: 2026년 9월 1일
```

류석균 원장은 `[류석균 원장](/doctors/ryu-seokgyun/) ｜ 임상 22년`을 쓴다.


## front matter

```yaml
---
title: "화면에 보이는 제목"
summary: "카드와 검색 결과에 나가는 두세 줄."
date: 2026-09-01
lastmod: 2026-09-01
share: false
authors:
  - seok-seonhui
tags:
  - 불면증
  - 칼럼
title_seo: "검색 결과에 나갈 제목"
faqs:
  - question: "질문"
    answer: "답"
---
```

| 항목 | 규칙 |
|---|---|
| `title` | 질문형이 기본이다. 12편 중 8편이 「~할까요?」 |
| `summary` | 두세 줄. meta description으로도 나가므로 160자를 넘기지 않는다 |
| `date` | **미래 날짜를 쓰지 않는다.** 미래면 화면에 나오지 않는다 |
| `lastmod` | `date`와 같게. 나중에 고치면 그날로 바꾼다 |
| `authors` | `seok-seonhui` 또는 `ryu-seokgyun`. 다른 값은 없다 |
| `tags` | 질환명 + `칼럼`. `칼럼`은 화면 필터에서 자동으로 빠진다 |
| `title_seo` | 없으면 `title`이 쓰인다. 검색용으로 조금 길게 |
| `faqs` | 본문 「자주 묻는 질문」과 같은 내용. 구조화 데이터로 나간다 |

### 쓰는 태그

이미 쓰이고 있는 값만 쓴다. 새 태그를 만들면 필터 버튼이 하나 늘어난다.

```
자율신경실조증 · 불안장애 · 다한증 · 공황장애 · 불면증
ADHD · 우울장애 · 신경성 질환 · 강박장애 · 틱장애
```

### 파일 이름

`content/column/<영문-하이픈>.md`. 이 이름이 그대로 주소가 된다.
**올린 뒤에는 바꾸지 않는다** — 주소가 바뀌어 기존 링크가 끊긴다.

기존 이름을 보면 규칙이 보인다.

```
why-insomnia-becomes-chronic          왜 ~한가
adhd-vs-normal-distractibility        A와 B의 차이
dysautonomia-symptoms                 무엇의 무엇
```


## 참고자료

12편 전부 이 구역이 있다. **해외 공신력 기관**의 페이지를 4개 안팎 단다.

```markdown
## 참고자료

*아래 자료는 모두 외부 기관이 제공하는 정보로, 클릭하시면 새 사이트로 연결됩니다.*

1. [CDC, Tourette Syndrome](https://www.cdc.gov/tourette-syndrome/about/index.html)
2. [NINDS, Tourette Syndrome](https://www.ninds.nih.gov/health-information/disorders/tourette-syndrome)
```

이미 쓰이고 있는 기관 — NINDS · CDC · NIMH · NHLBI · NHS · NICE ·
Cleveland Clinic · American Heart Association · WHO

**주소를 기억으로 쓰지 않는다.** 반드시 웹 검색으로 실제 존재하는 주소를
확인한다(이 작업 환경에서 `WebSearch`는 되고 `WebFetch`는 막혀 있다 —
검색 결과에 나온 주소만 쓴다).

확인되지 않으면 그 줄을 비워 두고 원장에게 보고한다. **없는 주소를 만들지
않는다.**


## 의료광고 — 쓰면 안 되는 표현

의료기관 홈페이지의 글은 광고물이다. 아래는 쓰지 않는다.

| 쓰지 않는다 | 대신 |
|---|---|
| 완치 · 100% · 부작용 없는 · 최고 · 유일 | 쓰지 않는다 |
| 「~때문입니다」로 원인 단정 | 「~가 관여하는 것으로 봅니다」 |
| 특정 뇌 구조를 원인으로 지목 | 기능·회로 수준으로 서술 |
| 「반드시 좋아집니다」 | 「경과를 관찰하며 평가합니다」 |
| 논문·후기를 근거로 효과 단정 | 「보고했습니다 / 연구했습니다」 |

**부정 맥락은 괜찮다.** 「보장할 수 없습니다」 「단독으로 확진하지 않습니다」는
오히려 필요한 표현이다.

증상이 위험할 수 있는 경우에는 **의료기관 진료를 권하는 문장**을 넣는다.
기존 컬럼들이 「위험 신호」 구역을 두는 이유다.

## 발행 전 점검

원장 검수를 받은 뒤에 한다.

```
hugo                              빌드가 통과하는가
python3 tools/check-mobile.py     모바일 규칙이 빠지지 않았는가
```

그리고 아래를 확인한다.

- 컬럼 목록 · 홈 · 게시판 · 작성자 페이지에 나오는가 (전부 자동이다)
- 본문의 내부 링크가 실제 있는 쪽을 가리키는가
- 금칙 표현이 남아 있지 않은가
- 참고자료 주소가 전부 확인된 것인가

**질환 페이지 연결은 자동이 아니다.** 그 질환 페이지에도 띄우려면
`content/diseases/<질환>.md`의 `related_columns`에 한 줄 추가한다.

```yaml
related_columns:
  - /column/why-tics-wax-and-wane/
  - /column/새-컬럼-파일명/
```

발행은 `master`에 커밋·푸시하면 Cloudflare가 1~2분 안에 반영한다.


## 공지사항

컬럼과 규칙이 다르다. 훨씬 단순하다.

```yaml
---
title: "추석 연휴 휴진 안내"
_build:
  render: never
summary: "추석 연휴 휴진 일정을 안내드립니다."
date: 2026-09-01
authors:
  - seok-seonhui
  - ryu-seokgyun
tags:
  - 공지
---

안녕하세요, 해아림한의원 잠실점입니다.

(본문)
```

- **`_build: render: never`를 반드시 넣는다.** 공지는 목록에서 펼쳐 보는
  방식이라 단독 페이지를 만들지 않는다. 빼면 기존 두 건과 형태가 달라진다
- 본문은 「안녕하세요, 해아림한의원 잠실점입니다.」로 시작한다
- 참고자료·FAQ·마무리 서명은 붙이지 않는다
- 홈 · 공지사항 · 게시판 세 곳에 자동으로 나오고 최근 글에는 NEW가 붙는다
