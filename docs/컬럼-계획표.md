# 원장 컬럼 계획표

**목요일·일요일 주 2회.** 일요일은 석선희 원장, 목요일은 류석균 원장이다.
위에서부터 하나씩 가져다 쓴다. 발행하면 그 줄에 ✅를 넣는다.

작성 규칙은 `컬럼-작성-가이드.md`, 클로드 프로젝트에 올릴 파일은
`클로드-프로젝트/README.md`를 본다.


## 절대 지킬 것 — 질환 페이지 FAQ와 겹치지 않게

질환 페이지 9개에 이미 FAQ가 **38개** 있다. 같은 질문을 컬럼 제목으로
다시 쓰면 **한 사이트의 두 페이지가 같은 검색어로 경쟁**한다. 검색엔진이
어느 쪽을 보여줄지 못 정하면 둘 다 순위가 내려간다.

| | |
|---|---|
| 질환 페이지 FAQ | 3~4문장 짧은 답 |
| 컬럼 | 그 질문 **하나로 한 편** |

컬럼을 발행하면 **질환 페이지 FAQ에서 그 컬럼으로 링크**를 건다.
그러면 경쟁이 아니라 보강이 된다. 발행 때마다 잊지 않는다.

**이미 발행한 컬럼과도 겹치지 않게 한다.** 아래 「이미 발행한 20편」을
먼저 본다. 제목이 비슷하면 각을 바꾸거나 그 글로 링크해서 넘긴다.


## 제목은 환자가 쓰는 말로

이번 분기부터 제목 규칙을 바꿨다. 「A와 B는 어떻게 다를까요?」 같은 틀보다
**진료실에서 환자가 실제로 하는 말**이 검색어에 가깝다.

```
아무것도 하기 싫고 계속 누워 있고 싶어요. 번아웃일까요, 우울증일까요?
목과 뒤통수가 조이듯 아픕니다 — 긴장성 두통
우리 아이 틱장애, 그냥 두고 지켜봐도 될까요?
```

질문형은 그대로 유지한다. 다만 병명으로 시작하지 말고 증상·상황으로 연다.

## 쓸 때 조심할 네 편

**4번 · 스트레스를 받으면 왜 몸이 먼저 아플까요?**
발행된 자율신경 두 편(「이유 없는 두근거림과 불안」·「자율신경실조증은 어떤
증상으로」)과 기전 설명이 정면으로 겹친다. **기전은 그 글로 링크하고**, 이
글은 「증상이 어디로 나오는가 · 어느 과를 먼저 가야 하는가」에만 머무른다.

**14번 · 검사는 다 정상인데 여기저기 아픕니다**
발행된 「검사에는 이상이 없는데 왜 자꾸 어지러울까요?」와 출발점이 같다.
어지럼 말고 **두통·소화·통증·피로를 아우르는 쪽**으로 넓혀야 구분된다.
신체화장애는 정신과 진단명이므로 **제목과 본문에서 진단을 단정하지 않는다.**

**12번과 22번 · 과민성대장증후군 두 편**
12번은 소아(시험·긴장), 22번은 성인(출근·회의)으로 상황을 확실히 갈라야
한다. 기전 설명은 한쪽에만 두고 다른 쪽에서 링크한다.

**1번 · 공황장애와 심장질환**
공황·불안 페이지 FAQ에 「공황장애와 심장질환은 어떻게 다른가요?」가 이미
있다. 발행 뒤 그 FAQ에서 이 컬럼으로 링크한다.
