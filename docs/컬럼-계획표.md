**목요일·일요일 주 2회.** 위에서부터 하나씩 가져다 쓴다. 다 쓰면 이 표를 갱신한다.

작성 규칙은 `컬럼-작성-가이드.md`, 클로드 프로젝트에 올릴 파일은

## 왜 이렇게 짰는가

2026-09-04 기준 14편을 실측했더니 두 가지가 치우쳐 있었다.

**질환별** — 불안·자율신경 4편씩인데 강박·우울·틱·ADHD·신경성은 1편씩.

**유형별** — 이쪽이 더 심했다.

| 유형 | 당시 |
|---|---|
| 「왜 ~할까요?」 원인 | 7편 (절반) |
| 「A와 B는 어떻게 다를까요?」 감별 | 2편 |
| 「~할 때 어떻게 해야 할까요?」 대처 | 1편 |
| **치료·경과** | **0편** |

환자는 대체로 이 순서로 검색한다.

```
① 내가 이 병인가  →  ② 왜 생겼나  →  ③ 지금 뭘 하나  →  ④ 치료받으면 어떻게 되나
```

**④는 내원을 결정하기 직전에 찾는 유형인데 한 편도 없었다.** 그래서 앞쪽
일정에 ④와 ③을 몰아 두었다. ②는 이미 충분하므로 뒤로 뺐다.


## 절대 지킬 것 — 질환 페이지 FAQ와 겹치지 않게

질환 페이지 9개에 이미 FAQ가 **38개** 있다. 같은 질문을 컬럼 제목으로
다시 쓰면 **한 사이트의 두 페이지가 같은 검색어로 경쟁**한다. 검색엔진이
어느 쪽을 보여줄지 못 정하면 둘 다 순위가 내려간다.

| | |
|---|---|
| 질환 페이지 FAQ | 3~4문장 짧은 답 |
| 컬럼 | 그 질문 **하나로 한 편** |

컬럼을 발행하면 **질환 페이지 FAQ에서 그 컬럼으로 링크**를 건다.
그러면 경쟁이 아니라 보강이 된다. 발행 때마다 잊지 않는다.

## 운영 규칙

**한 주에 두 편을 몰아 쓰지 않는다.** 목요일 글은 화요일까지, 일요일 글은
금요일까지 초고를 넘긴다. 원장 검수 시간을 남기는 것이 이 계획의 핵심이다.

**밀리면 건너뛰지 말고 미룬다.** 순서를 지키는 편이 낫다. 두 편이 밀리면
그 주는 한 편만 낸다.

**발행할 때마다 하는 것**

1. 질환 페이지 `related_columns`에 한 줄 추가
2. 질환 페이지 FAQ 중 겹치는 질문이 있으면 그 컬럼으로 링크
3. `클로드-프로젝트/사이트-지도.md`의 컬럼 목록에 한 줄 추가
4. 이 표의 해당 칸에 ✅

**3개월 뒤(12월) 재조정.** 그때는 구글 서치 콘솔에 어떤 검색어로 들어오는지
쌓여 있다. 수요가 큰 질환에 가중치를 주고, 반응 없는 유형은 뺀다.
지금 순서는 데이터가 없는 상태에서의 추정이다.

**컬럼이 30편을 넘으면** 목록 페이지에 페이지네이션이 필요한지 본다.
필터는 이미 있으므로 그것만 확인하면 된다.
